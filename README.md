# Fake News Detection

A Natural Language Processing project that classifies news articles as fake or real using traditional machine learning techniques.

## Dataset

[Fake and Real News Dataset](https://www.kaggle.com/datasets/bhavikjikadara/fake-news-detection)

The dataset contains two collections:
- Fake news articles
- Real news articles

## Approach

1. Load and combine the fake and real news datasets.
2. Explore and preprocess the text data.
3. Split the data into training and testing sets.
4. Convert text into numerical features using TF-IDF.
5. Train and evaluate machine learning classifiers.

## Models

- Logistic Regression
- Linear Support Vector Classifier (Linear SVC)

## Technologies

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib

## Notebook

The `notebook.ipynb` file contains the complete workflow, including data exploration, preprocessing, model training, and evaluation.
